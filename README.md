# Instagram Usage Lifestyle Analysis 

📌 Project Title:

Instagram User Engagement & Lifestyle Impact Analysis

🔎 Problem Statement:

With the rapid growth of social media usage, understanding what drives user engagement is critical for platform optimization and targeted marketing.

The objective of this project was to:

* Analyze how demographic, lifestyle, and behavioral factors influence Instagram engagement.
* Build a predictive model to estimate User Engagement Score.
* Identify key features that significantly impact user engagement.

The dataset contained 1.5M+ user records with 58 features including:

* Demographics (age, gender, country, income)
*  Health & lifestyle factors (sleep, stress, exercise, BMI)
* Instagram usage metrics (reels watched, posts created, session time, followers, ads clicked)
* Account behavior (notification response rate, subscription status, privacy level)

## Project Overview

* Developed an end-to-end data analytics project to analyze Instagram user behavior, engagement patterns, and lifestyle usage trends.
* Built an interactive Power BI dashboard to visualize user engagement, posting activity, reels consumption, follower growth, and subscription behavior.
* Used SQL for data extraction and business analysis queries.
* Performed data preprocessing and exploratory data analysis (EDA) using Python in Jupyter Notebook.

* Notification response rate positively affected engagement.
